Instructions:
Simply just type in the information asked by terminal ie. suburb, city or address







How it works: 
1.Takes a typed location and geocodes it into latitude/longitude
2.Searches the Places API for nearby cafes within a 1.5km radius
3.Sorts and displays the results in the terminal
4.Possible improvements
5.Add a Flask/Streamlit web interface
6.Show results on an embedded map
7.Let the user adjust the search radius
8.Cache results to reduce API calls

Tech stack:
Python (PyCharm)
google maps (official Google Maps API client library)

Author:
Built by Jeandre Oosthuizen as a portfolio project to practice working with third-party REST APIs in Python.
